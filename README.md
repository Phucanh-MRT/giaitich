# Sổ Giải Tích

Sổ tay học giải tích dạng web tĩnh: Mở đầu + 36 chương, 236 mục, minh hoạ tương tác, bài tập có lời giải, ôn thẻ và đề thi trắc nghiệm tự chấm.

- Chạy hoàn toàn trong trình duyệt, không cần máy chủ hay AI.
- Tiến độ và ghi chú lưu trong trình duyệt (localStorage); sao lưu ở trang **Ghi chú**.
- Chạy trên máy: `python -m http.server 5178` rồi mở `http://127.0.0.1:5178`.

Nội dung giải thích, ví dụ và bài tập được viết riêng, chỉ dựa theo cấu trúc mục lục của các giáo trình giải tích tham khảo.
